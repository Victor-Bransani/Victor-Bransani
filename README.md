## Selected work

### [Melanoma Mapper Pro](https://github.com/Victor-Bransani/melanoma-mapper-pro)

A healthcare frontend for mapping skin lesions on an interactive 3D human model
and following each patient's analysis history. The project includes typed API
contracts, authentication flows and automated tests.

`React` · `TypeScript` · `Three.js` · `Vitest` · `Playwright`

### [Sistema de Reservas](https://github.com/Victor-Bransani/sistema-reserva)

A reservation platform for spaces and resources, with calendar views, approval
flows, recurring bookings, reports and a relational SQL Server schema.

`React` · `TypeScript` · `Tailwind CSS` · `SQL Server`

### [Sistema de Pedidos](https://github.com/Victor-Bransani/sistema-pedido-appscript)

A role-based purchase-order workflow that converts PDFs into structured data
with Gemini, stores records in Google Workspace and tracks receiving and pickup
statuses.

`Google Apps Script` · `Gemini API` · `Google Sheets` · `Google Drive`
